If the error says
The detected CUDA version (13.0) mismatches the version that was used to compile
    PyTorch (12.4). Please make sure to use the same CUDA versions.

Install Cuda Toolkit 12.4 by going
    https://developer.nvidia.com/cuda-12-4-0-download-archive

And in the installation click advance
    Click this <Cuda -> Development -> Compiler>
    Click this <Cuda -> Runtime -> Libraries>
    Uncheck everything else

After that we want to make sure it is installed here
C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.4
